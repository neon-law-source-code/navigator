# Public images

Read the relevant content source, [`docs/assets.md`](../../../docs/assets.md), and
[`docs/public-contributor-safety.md`](../../../docs/public-contributor-safety.md).

- Use only rights-cleared, public-safe images and accurate alt text. Keep local assets and captures out of Git where
  the documented asset workflow requires it.
- Verify the image reference locally; do not deploy or mutate cloud storage without explicit authorization.
- Never treat a crop, blur, or redaction as a license to publish client material, legal files, real contact details, or
  production identifiers.
